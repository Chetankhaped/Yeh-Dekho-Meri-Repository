Detection Models

Our system employs three specialized deep learning models that work together to provide comprehensive deepfake detection:

🎯 Pinpoint (Primary Ensemble Model)

Advanced transformer-based model providing detailed frame-by-frame analysis:

  • Audio-Video Synchronization: Analyzes correlation between audio RMS and mouth openness
  • Attention Patterns: Uses cross-attention mechanisms to detect anomalies
  • Mel Spectrogram Analysis: Examines audio frequency patterns for artifacts
  • Temporal Consistency: Tracks frame-by-frame energy patterns

🔍 VGG16 v1 (Visual Analysis Specialist)

Convolutional neural network focused on visual artifact detection:

  • Texture Patterns: Hierarchical texture feature extraction using deep convolutional layers
  • Edge Detection: Sobel and Canny algorithms to identify manipulation boundaries
  • Color Consistency: Histogram distribution analysis across temporal sequences
  • Transfer Learning: Leverages ImageNet pre-training for unnatural pattern recognition

🎨 VGG16 v2 (Gradient & Artifact Detector)

Enhanced VGG16 variant specializing in compression artifacts and gradients:

  • Texture Patterns: Gabor filters and Local Binary Patterns for texture discontinuities
  • Gradient Analysis: Spatial gradient analysis to detect unnatural transitions
  • Artifacts Detection: JPEG compression artifacts and re-compression pattern identification
  • Frequency Domain Analysis: Detects frequency anomalies indicating digital manipulation

📊 Ensemble Approach

The system combines predictions from all three models to provide a robust confidence score. Each model contributes its specialized analysis, resulting in more accurate and reliable detection than any single model could achieve alone.

Technical Specifications

  • Architecture: Multi-model ensemble (Pinpoint + VGG16 variants)
  • Input Resolution: 224×224 pixels for VGG16 models
  • Supported Formats: MP4, AVI, MOV videos; JPG, PNG images
  • Analysis Types: Visual, audio, and audiovisual synchronization
  • Confidence Scoring: 0-100% manipulation probability
  • Processing: GPU-accelerated deep learning inference
